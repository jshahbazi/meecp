## Corrections made before acceptance

The first full run found a stale resolved-application test that supplied only an internal flag. Production forms now require the actual inspected kind. The corrected test covers both `python-callable` and `python-mcp` and rejects the actual emitted agent/native kinds for that recipe.

The next full run failed a timing-sensitive resource assertion. Independent repetitions reproduced four `membership_changed` rejections in 20 footprint attempts: the fixture forked between membership snapshots, and the native sampler correctly failed closed before checking the footprint threshold. All 83 diagnostic attempts settled pending ownership and reserved units with inadmissible results. The original failure's exact parameter and reason were not retained, so the reproduction establishes the fixture defect without claiming the original attempt's precise reason.

The footprint fixture now touches 24 MiB in one process and waits, preserving the exact 16 MiB threshold assertion. Forking positive/process controls remain. The deterministic private-helper membership fault still checks the exact rejection and now asserts both zero pending ownership and zero reserved units. No production policy, native helper or resource claim changed.

Both corrections cleared independent review before the successful complete regression. Published component and recipe bytes were preserved; no new runtime recipe version was required.

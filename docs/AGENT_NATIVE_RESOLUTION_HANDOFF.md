# Native review of staged agent proposals

An unlocked agent analysis can finish with a reviewed proposal and no executable
candidate. The host stages its derived inputs for ordinary dependency resolution
at the same saved import revision. Previously the native agent panel only said
that further review was needed; rebinding the unchanged draft left the old
preparation form in place.

The settled proposal now offers **Review Preparation**. This owner action asks
the ordinary preparation view to rediscover the current host form. It performs
no candidate-adoption request, dependency resolution, build or installation.
The normal form determines the remaining questions and blockers; dependency
resolution still requires its separate review and start actions. Proposals that
remain unsupported retain the host's blockers.

The action requires a current succeeded, settled job with a proposal digest and
the exact saved draft context. The parent also checks the current editable,
unattached directory, source identity and revision; private host connection;
and idle capture, agent and ordinary preparation controls. Offline, dirty,
changed-context and owned-work states cannot start the form read.

Fresh discovery sends only the import identity and revision. It carries no older
candidate, recipe or dependency-result hint. Completed preparation and
resolution display state is cleared before this read; active or unresolved
resolution ownership prevents the handoff. Existing form request epochs reject
late replies after the draft changes or becomes unsaved. A locked executable
candidate continues to use its existing host-validated adoption path.

Actual AppKit contract controls cover the explicit form read, zero automatic
starts, subsequent separately reviewed resolution, disabled direct selectors,
missing proposal or callback, unsettled and terminal states, changed import,
revision and source, offline/unsaved/ineligible views, outstanding form requests,
active jobs, retained resolution ownership, old selection hints and late replies.
Synthetic self-test fixtures are shared internally by the two native views.

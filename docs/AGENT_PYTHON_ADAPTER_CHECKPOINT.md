## Authority and ownership

The derivation journal binds the original import and full source revision, host plan, request, coordinator proposal and attempt, selected recipe and epoch, exact component, usage policy and expiry. Generated code never becomes a trusted catalog implementation. Adopting a candidate selects its descriptor; it does not start preparation, enable a recipe or install an App.

The closed proposal consumes every proposed file. It requires the original `pyproject.toml`, `uv.lock` and source license, checks the exact original lock digest, rejects unresolved outputs and reserves `meecp_generated_agent_adapter.py`. Static AST and schema checks establish eligibility. They do not establish runtime safety or absence of effects.

The journal owns a private collection containing only the wrapper, its license and interface metadata. It records exact file identities before writing bytes, pins original and derived metadata around full validation, and retains interrupted state until an explicit recovery or deletion can prove settlement. Cancellation joins the actual validation worker. Recovery refuses an active worker; deletion refuses replacement inodes. Original source bytes and generated bytes keep separate provenance and license records.

Current-input checks compare the same durable baseline at adoption, build and attachment. The returned common hook runs after the existing draft and recipe checks. It accepts only synchronous literal `True`; it performs metadata checks without reading file contents inside the import transaction. The common confined verifier remains mandatory for this family.

## Reproduction and integration

Run the source tests with locked dependencies:

```text
uv run --locked pytest -q --tb=no --show-capture=no tests/test_preparation_agent_adapter.py tests/test_preparation_agent_adapter_pipeline.py
```

The actual pipeline is opt-in. It requires `MEECP_AGENT_ADAPTER_HOST` to name a verified private host, `MEECP_AGENT_ADAPTER_COMPOSITION` to name an exact private source inventory, and `MEECP_AGENT_ADAPTER_RECEIPT` to name a fresh private receipt path. The selected source composition must include the common confined verifier and returned authority hook. Diagnostics and receipts contain bounded stages, counts, types and hashes; they omit source, prompts, responses, secrets and raw exception dumps.

The minimal shared registration patch is [agent-adapter-registration.patch](patches/agent-adapter-registration.patch). It adds the trusted component, family and default recipe, initializes the durable derivation store, and adds the optional metadata current-input hook. Public provider execution and ordinary preparation remain closed by default. A private harness admits only this exact family and explicitly enables the synthetic recipe.

## Remaining A5 work

Unfamiliar unlocked directories still need governed dependency derivation through the trusted resolver, immutable lock and wheel receipts, offline build and license notices. The final user workflow must not require users to author locks or manifests. Live configured-provider transfer, credential proof, cost evidence, native generated-adapter interaction, a newly built combined artifact and full installed lifecycle remain open. Simulated responses do not prove a provider can generate a correct adapter. Hard aggregate resource enforcement and whole Phase 3 acceptance remain open.

# Installed host-command checkpoint

Status: isolated implementation for explicit development admission. A3 remains open. The default host does not advertise or enable this profile. No published recipe bundle is changed, and no preparation generator selects this profile.

## Package and host contract

Manifest schema 2 accepts only `profile: host-command`; schema 1 retains its existing model and profile interpretation. The schema-2 `command` declaration has version 1, component `macos26-arm64-command-v3`, an exact trusted host-helper SHA-256, fixed package-relative executable/cwd/argv for every advertised tool, a command deadline, bounded JSON input/output, and a queue bound. Tools must declare object input/output schemas with closed top-level properties. The package permits no configuration, secrets, filesystem grants, network grants, writes, resident processes, or caller-selected executable/argv/environment. Arguments arrive as one JSON stdin object; exit zero and one schema-valid JSON output object produce `CallToolResult`. Nonzero exit and malformed output produce a sanitized MCP error.

Static validation verifies the complete artifact tree, executable modes, hashes, paths and license entries using the existing package lock and snapshot boundary. A command declaration does not authorize execution. A trusted embedding host must supply `HostCommandAdmission(helper, helper_sha256)` to `Supervisor`; the package helper identity must match it. Public CLI/API requests cannot create this admission. This checkpoint has no runtime compiler, PATH-based helper discovery, or new management bearer token.

Schema 2 accepts only a bounded structural schema subset so selected validation logic cannot stall the host. Closed objects, bounded arrays/strings, primitive scalar types, finite numeric bounds and bounded scalar enums are supported. Each schema has at most 128 nodes, depth 8, 32 properties/required names per object, 32 enum values, and 64 array items. Strings require `maxLength` no larger than the invocation byte ceiling or 16,384; enum and descriptive strings have byte bounds. Regex, references, combinators, dependencies and unknown keywords fail statically with `unsupported_host_command_schema`. Accepted schemas are published exactly, including nested schemas. Schema 1 is unaffected.

`Supervisor.commands` owns command execution. A trusted host protocol task supplies the same private stdin/stdout descriptors that the existing gateway expects. It is a distinct handle, never a fabricated `OwnedProcess` or legacy receipt. HTTP and stdio clients keep the existing gateway authentication, Host/Origin checks, schemas and request bounds. Selected package code is never imported into the host.

## Ownership and authority

The native command owner is a direct child of the backend and starts its own session before native code runs. Its confined target establishes a separate group; inherited syscall policy prevents target descendants escaping it. Gateway or ancestor group death cannot kill the isolated native owner through that group's signal. Actual helper loss remains unresolved and retains reservations. No recovery path adopts or signals a recorded PID.

Each call binds an opaque invocation identity to slot ID, generation, package digest, complete tool schema, complete command declaration, session, request identity and native platform policy. The resulting digest is included in the native command specification and therefore in its exact format-3 receipt binding. Caller arguments and source/output content never enter durable state.

The host reserves declared memory accounting under its resource lock, then durably records the invocation identity/specification digest before native execution. The native journal is durable before `Popen`. A host record without a native journal entry therefore proves nonlaunch. A matching native entry requires a valid published format-3 completion; staged C/N bytes do not release it. Missing/invalid proof blocks replacement execution, upgrade/removal completion and reservation release. Journal capacity is deliberately finite (256 attempts per slot); this checkpoint does not implement retirement/compaction.

Queue admission is bounded per slot across sessions. Its wait consumes the original command deadline. Results recheck package/generation authority before publication and after each pipe-backpressure wait. Session loss, gateway loss, stop and shutdown close admission and join native cancellation; cleanup does not kill the native owner. Startup reads command records and exact receipts before opening gateways. Incomplete records restore memory accounting even if the separate slot reservation file is absent; an unmatched pending native journal takes a conservative blocking reservation. Legacy gateway ownership remains a separate recovery requirement.

The native format-3 publication semantics are unchanged: final payload and mode are fsynced, writable completion descriptors close, and an exclusive FD-relative rename publishes the final name. No fallible payload sync follows publication. Missing final directory entry always retains ownership; directory-entry crash persistence is not claimed by the payload barrier.

## Evidence and limits

`tests/test_host_command.py` compiles synthetic native fixtures and installs them through the real Supervisor install/snapshot workflow. Real SDK clients use both authenticated HTTP and the existing stdio bridge. The fixture's original source package is removed before subsequent calls. Tests cover descriptor exclusion, fork/exec descendants, denied group escape, cancellation joins, bounded queue/deadline, exit/output rejection, generation changes during result publication, private closure tampering, backend SIGKILL, held ancestor-group SIGKILL, native-owner loss, pending removal/restart, and host death during successful or failed prepublication sync. Test-only native failure variants are compiled separately; production has no fault switches. Synthetic orphans have an independent finite alarm for helper-loss tests.

These are installed-slot checks in the development host runtime. They do not establish a relocated, signed native app bundle with its final helper identity, native menu stop/watchdog behavior, or packaged private runtime closure. Those artifacts require their own build and installed proof before release. The constructor admission stays closed by default.

Independent final review passed all 81 installed/native cases with unchanged production hashes, a separate 49-case schema boundary matrix, and the original corrected-finding reproductions. Those checks confirmed early-close descriptor cleanup, fresh-session admission during a healthy call, fixed-size duplicate-ID tracking, completed-removal executor retirement, static rejection of selected regex, and completion remaining unpublished until retirement joins. The final legacy host/management/upgrade/package packet passed 217 with one skip; the final removal-publication correction additionally passed all 28 targeted/legacy-management cases. A broader native/package/host/lifecycle regression packet passed 389 with one skip before the last bounded-state corrections, followed by targeted regressions for those corrections. A broad regression run passed 2,198 with 43 skips and one deselection while excluding the known text-generation-identity-dependent modules. The initial complete run had nine failures tied to the old immutable text-generation component identity (plus a schema-rejection code regression subsequently fixed). Fresh catalog inspection reports only `mcpme.text-generation` blocked by `builtin_recipe_component_mismatch`; other builtin families remain ready. Existing recipe bundles were preserved. A newly versioned component bundle and a complete combined-host run are still required after root integration; these results are not a claim of an all-green final application suite.

Aggregate process count and whole-tree physical memory enforcement remain unresolved. Inherited per-process rlimits multiply with forks; `RLIMIT_NPROC` is per user; sampling RSS is reactive measurement. The earlier [primary-source assessment](COMMAND_INSTALLED_INTEGRATION_CONTRACT.md#resource-boundary-remains-unresolved) found no demonstrated supported unprivileged macOS API for a per-invocation hard aggregate memory/process domain. This implementation does not substitute accounting for enforcement and does not claim A3 completion.

# Resolved Python app

Host-owned metadata for ordinary Python callables and foreground tools-only MCP servers. Dependency locks and discovered interfaces come from an explicitly authorized owned resolution result. Original source files retain their identity. Generated questions collect synthetic fixtures and exact access and resource choices. Metadata enablement grants no execution or installation authority.

Version 1.0.1 binds the trusted complete application-directory snapshot adapter. Binary assets and unknown regular payloads remain in the captured source closure. Published version 1.0.0 bundle bytes remain retained.

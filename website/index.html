A FEW GOOD QUESTIONS

Before you
move in.

What is MCP?+

The Model Context Protocol gives AI clients a standard way to discover and call tools. Meecp hosts local tool packages and provides connection setup for clients that support MCP.

Which Macs can run meecp?+

The current project targets Apple silicon Macs running macOS 26 or later. Runtime and memory requirements depend on the packages you install. Intel Macs are outside the current scope.

Does it include a chat app?+

Meecp is a host for tools and local models. Connect it to an MCP client to use those tools in your workflow. The JevK5 package handles typed decisions from supplied evidence.

What’s available to download today?+

The latest public installer is v1.0.0, published under the former mcpme name. This site describes the current meecp development project; newer features may require a source build. Review the release notes and project status before installing.

What should I know about app packages?+

Installed packages run with your account’s permissions. Hash verification checks downloaded bytes; you still need to trust the publisher. Support for arbitrary generated projects is evolving, and the current package integration focuses on MCP tools.
